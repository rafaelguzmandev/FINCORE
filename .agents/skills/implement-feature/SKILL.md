# Implement Feature

## Purpose

Implement a feature based on an approved FinCore specification.

## Procedure

1. Read AGENTS.md.
2. Read the applicable feature specification.
3. Inspect the relevant service and existing patterns.
4. Identify affected files and dependencies.
5. Present a concise implementation plan.
6. Identify required tests before coding.
7. Implement only the approved scope.
8. Run relevant tests and quality checks.
9. Review the final diff.
10. Report changes, test results and remaining risks.

## Constraints

- Do not invent business rules.
- Do not change unrelated services.
- Do not introduce unnecessary abstractions.
- Do not alter approved contracts without approval.
- Ask when a requirement is ambiguous.
